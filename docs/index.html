Content Refresh Opportunity Scoring

A Data-Driven Framework for Prioritizing Search Content Reviews

Sukanya Bodke

FlyRank ML Internship — Refresh / Content Opportunity Scoring

Abstract

This project investigates which content items should be prioritized for review or refresh using observed search performance, content age, update history, visibility, and engagement signals. The analysis uses an anonymized dataset containing 30,000 content records and 44 columns from the FlyRank ML Internship dataset. A transparent opportunity-scoring baseline was created and compared with a Random Forest model for predicting recent performance trend. The Random Forest model did not outperform the simple baseline on the held-out test set, with an MAE of 75.64 compared with 71.89 for the baseline. The final output is therefore used as a decision-support ranking that helps content practitioners identify items for human review rather than as a guarantee of future performance improvement.

1. Problem Statement

The project supports the decision of which content items should be reviewed first for a possible refresh.

Unit of analysis: Each row represents one anonymized content item.

Output: A ranked opportunity score from 0 to 100, together with an action recommendation and reason codes.

Human action: A content or SEO practitioner can use the ranked list to decide which pages should receive closer review, possible refresh consideration, monitoring, or protection from unnecessary changes.

The ranking is intended to support human judgment rather than automatically determine actions.

2. Data

The analysis uses the public-safe, anonymized FlyRank internship dataset containing 30,000 content records and 44 columns.

Main signals used include:

  • Content age
  • Days since last update
  • Search impressions
  • Click-through rate (CTR)
  • Average search position
  • Word count
  • Recent impressions
  • Recent performance trend

The pseudonymous identifiers content_id and client_id were not used as predictive features.

No client names, domains, private search queries, credentials, or raw private exports are included in the analysis or recommendations.

3. Methodology

A transparent rule-based opportunity score was created first. The score combines content age, time since update, search visibility, CTR, and negative recent trend.

  • Content age — 25%
  • Days since last update — 25%
  • Search visibility — 20%
  • Lower CTR — 15%
  • Negative recent trend — 15%

A Random Forest regression model was then tested using:

  • content_age_days
  • days_since_last_update
  • impressions_90d
  • ctr
  • avg_position
  • word_count

The model predicted trend_pct. Identifiers and trend-derived fields were excluded from the predictive feature set.

The Random Forest did not outperform the simple baseline on the held-out test set. The negative R² indicates that the model did not provide useful additional predictive performance compared with the baseline.

The machine-learning experiment is therefore reported as a validation finding rather than as a superior predictive model.

5. Ranked Recommendations

The baseline opportunity score was used to create a ranked list of content items for human review.

Recommendation Categories

  • Refresh: Higher opportunity signals requiring detailed review.
  • Review: Moderate opportunity signals requiring examination.
  • Monitor: Weaker signals that may be observed over time.
  • Protect: Lower opportunity scores where unnecessary changes may be avoided.

The highest-ranked content item received an opportunity score of approximately 84.53. It was 504 days old, had not been updated for 104 days, had 2,294 impressions over the trailing 90 days, a 0.00% CTR, and a recent trend of -88.8%.

These recommendations are prioritization suggestions rather than automatic instructions.

6. Limitations and Honest Framing

  • The dataset contains observational content-performance signals and cannot establish that refreshing content will cause better search performance.
  • The Random Forest did not outperform the simple baseline.
  • The opportunity score is a prioritization heuristic, not a prediction of guaranteed future performance.
  • The analysis uses anonymized content-level data and excludes private client information.
  • Human review remains necessary because factors such as content quality, business importance, search intent, and strategic priorities are not fully represented in the dataset.
